How to use this

Two sittings per domain, on different days. Day one, read the study guide then run Learn a section. Day two, run Test a section cold.

Above 85 percent, move on. Between 70 and 84, work the misses and retest in three days. Below 70, reread the guide first.

After every run, open Review and note the task statement number of each miss, not the question. Repeat numbers mean a concept gap, and more questions will not fix it. Full procedure in HOW-TO-RUN-A-SECTION.md.
